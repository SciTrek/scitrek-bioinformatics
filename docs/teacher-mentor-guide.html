SciTrek Bioinformatics

Teacher & Mentor Guide

How to run a class session: help students create accounts, keep the room moving, and review student work. Pair this with the student login handout.

1. Links you need

  • Student site: https://bioinformatics-mod.sci-trek.org
  • Staff / mentor admin: https://bioinformatics-mod.sci-trek.org/admin/
  • Student handout: share docs/student-login-guide.html (or the printed PDF)

Mentor/teacher accounts are created by SciTrek staff. Use the username and password you were given — do not invent a student-style account for mentoring.

2. Before class checklist

  • Confirm the classroom code students should enter (example: 1001)
  • Confirm Days 1–5 modules are visible for that classroom (ask SciTrek if a day is missing)
  • Print or share the student login guide
  • Write the username/password pattern on the board
  • Test one mentor admin login and one sample student login
  • Know who to text/email if the site is down or modules are blank

3. Student username & password pattern (classroom convention)

This is a shared classroom format to make accounts easy to remember and easy for mentors to help recover. It is not enforced by the website code.

Username: P#G#FirstnameLastname

Password: SciTrek-P#G#Firstname!

Example that works:

  • Username: P1G1AndySubramanian
  • Password: SciTrek-P1G1Andy!
  • Classroom: 1001 (or the code SciTrek gives your site)

Important: Students should not use the username itself as the password. The site rejects passwords that are too similar to the username.

Board script you can say out loud:

  1. “Username is P, your period, G, your group, then FirstnameLastname with no spaces.”
  2. “Password is SciTrek-dash-P-period-G-group-Firstname-exclamation point.”
  3. “Classroom name is the code on the board.”

4. First 10 minutes of class (signup flow)

  1. Open the student site on the projector.
  2. Click Sign Up and walk through one example account.
  3. Have students create accounts using the pattern above.
  4. Once signed up, they can use Sign In next time with the same credentials.
  5. If a student already has an account, they should Sign In — not create a second account.

Guest mode: “Continue as Guest” is only for demos. Guest work may not stay with a real student identity. For class credit / mentoring, students should create real accounts.

5. Common student problems (and what to say)

  • “Sign up failed” / password too weak:
    Have them use SciTrek-P#G#Firstname!. Short or common passwords (like password) are blocked on purpose.
  • “Too many signup attempts” / throttled:
    The school network may be temporarily limited after many failed tries. Wait 15–20 minutes, then have each stuck student try once with the correct format.
  • Classroom does not exist:
    Re-check the classroom code spelling with SciTrek staff. Students must type it exactly.
  • Username already taken:
    Confirm period/group, or add a middle initial (example: P1G1AndyMSubramanian).
  • Days/modules are blank after login:
    Modules must be assigned/released for that classroom. Contact SciTrek staff to seed or release the day modules — students cannot fix this themselves.
  • Forgot password:
    There is no self-serve reset yet. Rebuild from the class pattern, or ask SciTrek staff to reset the account in admin.

6. During the activity

  • Students work in Days 1–5 on the student site after login.
  • Answers usually autosave — if a control looks frozen, try scrolling/closing any zoomed image overlay, then refresh.
  • Encourage students to keep username/password on a sticky note for this class only if your school policy allows it.
  • Circulate by period/group using the username pattern so you can find who needs help quickly.

7. Why we ask students for longer passwords

Student accounts hold workbook answers and progress. Short/common passwords are easy to guess, which can let someone open another student’s work or disrupt the activity. The longer class pattern still stays memorable for teens while meeting the site’s security checks.

8. When to escalate to SciTrek staff

  • Classroom code is missing or wrong
  • Modules/days do not appear for the whole class
  • Mentor admin login does not work
  • Site is down or login page will not load
  • You need a password reset for a student who cannot recover via the pattern

When escalating, include: school/site name, classroom code, approximate time, and 1–2 example student usernames (never send student passwords over email if you can avoid it).

10. Mentor quick checklist

  • Classroom code is on the board
  • Username/password pattern is on the board
  • Student handout is shared
  • I can log into admin
  • I can find Student responses for a test username
  • I know who to contact if modules are missing
