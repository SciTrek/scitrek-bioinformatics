SciTrek Bioinformatics

How to Create Your Account & Log In

A short guide for students. Please read this before your first class session.

1. Open the website

Go to: https://bioinformatics-mod.sci-trek.org

2. Use this class naming pattern

To make accounts easy to remember (and easy for teachers to help with), use this classroom convention. It is a shared format for students — not a special website rule — but it helps everyone stay organized.

Username format:

P#G#FirstnameLastname

  • P# = your period number (example: period 1 → P1)
  • G# = your group number (example: group 1 → G1)
  • FirstnameLastname = your name with no spaces

Example for Andy Subramanian in Period 1, Group 1:
Username: P1G1AndySubramanian

Password format (recommended):

SciTrek-P#G#Firstname!

Keep the same period/group/name idea, but start with SciTrek- and end with !. That keeps it easy to remember while still long/strong enough for the website.

Example for Andy:
Password: SciTrek-P1G1Andy!

Do not use your exact username as your password. The website will reject passwords that are too similar to your username (for example, P1G1AndySubramanian used as both).

3. Create a new account (first time only)

  1. Click Sign Up at the top of the login box.
  2. Enter your username using the pattern above (example: P1G1AndySubramanian).
  3. Enter your password using the pattern above (example: SciTrek-P1G1Andy!).
  4. Type the same password again in Confirm Password.
  5. Enter your first name and last name.
  6. Enter your classroom name exactly as your teacher gives it to you (for example, 1001).
  7. Click Sign Up.

Example that works:

  • Username: P1G1AndySubramanian
  • Password: SciTrek-P1G1Andy!
  • First name: Andy
  • Last name: Subramanian
  • Classroom: 1001 (use the code your teacher gives you)

Build yours the same way from your period, group, and name. Do not reuse a password you already use for email or school accounts.

4. Password rules (why the extra pieces matter)

The website still requires passwords that are:

  • At least 8 characters long
  • Not a common password (avoid password, 123456, qwerty)
  • Not only numbers
  • Not too similar to your username or name

That is why the class password pattern adds SciTrek- at the start and ! at the end: it stays memorable for students, but is long enough and different enough to be accepted.

Use:

  • SciTrek-P1G1Andy!
  • SciTrek-P2G3Jordan!

Avoid:

  • Using the username itself as the password
  • Short passwords like pass or P1G1
  • Common words like password or password123

5. Why do we need a longer password?

SciTrek stores your class work, answers, and progress. A short or common password is easy for automated programs (and curious classmates) to guess.

A longer, less common password helps protect:

  • Your workbook answers and quiz progress
  • Messages and files in your account
  • The fairness of the classroom activity (so someone else cannot pretend to be you)

This is the same idea used for school email and banking apps: longer passwords are much harder to crack, even if someone tries many guesses quickly.

6. Log in next time

  1. Open the same website.
  2. Stay on Sign In (not Sign Up).
  3. Enter the same username and password you created.
  4. Click Sign In.

Tip: If you forget your password, ask your teacher for help using the class pattern (period, group, and name). There is no self-serve “forgot password” link yet.

7. Quick checklist before class

  • I can open the SciTrek website
  • My username follows P#G#FirstnameLastname
  • My password follows SciTrek-P#G#Firstname!
  • I wrote down or remembered both
  • I know my classroom name/code from my teacher
  • I successfully signed in once before class starts

8. If something goes wrong

  • “Sign up failed” / password error: Use the recommended password pattern (SciTrek-P#G#Firstname!), not your exact username.
  • “Too many signup attempts” / throttled: Wait about 15–20 minutes, then try one time with the recommended format. Many failed tries from the same school network can temporarily pause signup.
  • Classroom does not exist: Double-check the classroom name with your teacher (spelling and numbers matter).
  • Username already taken: Confirm period/group numbers with your teacher, or add a middle initial (example: P1G1AndyMSubramanian).
